# 📧 Projeto VTEX – Disparo de E-mail com Master Data

Este projeto foi desenvolvido como parte de um desafio técnico utilizando a plataforma **VTEX IO**, com foco em integração com **Master Data V1**, disparo de **e-mails transacionais** e boas práticas de **UX, acessibilidade e validações**.

---

## 🚀 Instalação e VTEX Link

### Pré-requisitos
- Node.js
- VTEX Toolbelt (`npm install -g vtex`)
- Conta VTEX configurada

### Passos para rodar o projeto
```bash
vtex login {account}
vtex use {workspace}
vtex link
